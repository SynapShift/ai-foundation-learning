# Contributing

This repository welcomes contributions that make foundation model concepts easier to understand from first principles.

## Good Contributions

- Beginner-friendly explanations with clear motivation.
- Small code examples with shape and data-flow explanations.
- Exercises that diagnose understanding rather than reward memorization.
- Glossary entries that connect terms to nearby concepts.
- Common misconceptions written in a depersonalized way.

## Writing Standards

- Explain why a concept exists before giving the formal definition.
- Avoid saying "obvious", "simple", or "just" when introducing a difficult idea.
- Separate intuition from strict technical fact.
- Be explicit when a claim is model-specific or implementation-specific.
- Do not include private learning history, personal progress, answer records, or learner diagnostics.

## Privacy

Never commit `.local-learning/`, `.env`, keys, tokens, or personal learning logs.
