# Handbook

The handbook contains public, independently readable learning materials for foundation models.

Each page should help a learner move through:

```text
Why
-> Intuition
-> Real structure
-> Minimal formula
-> Code or implementation meaning
-> Connections to nearby concepts
```

The handbook is not a transcript. It should not refer to private learning history or personal progress.
