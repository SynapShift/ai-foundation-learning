# Glossary

## Foundation Model

A large model trained on broad data that can be adapted or prompted for many downstream tasks.

## Hidden State

The vector representation of a token at a particular layer of a model.

## Attention

A mechanism that lets tokens compute weighted information from other tokens.

## Query

In attention, the projected representation used to ask what this token should attend to.

## Key

In attention, the projected representation used to be matched against a query.

## Value

In attention, the projected representation that carries the information mixed by attention weights.

## Logit

A raw score before a probability function such as softmax.

## Softmax

A function that converts a list of scores into positive weights that sum to 1.
