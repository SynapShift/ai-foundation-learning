# Self-Study Prompt

Use this prompt when studying a foundation model concept independently.

```text
I want to understand the following foundation model concept:

[concept]

Please teach it in this order:
1. Why it is needed
2. The core intuition
3. A concrete example
4. The real model mechanism
5. The smallest useful formula
6. A minimal code sketch, if relevant
7. Common misconceptions
8. One diagnostic question to check my understanding

Please avoid jargon dumps. If a term is necessary, define it in plain language.
```
