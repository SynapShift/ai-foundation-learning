# AI Foundation Handbook

A bilingual, chapter-based handbook for learning large language models from first principles.

- [Read in English](handbook/en/index.md)
- [阅读中文版](handbook/zh/index.md)
- [Web edition](https://synapshift.github.io/ai-foundation-learning/)

Public content lives in [`handbook/`](handbook/). Each chapter includes explanations, reusable questions, and reference answers. The website is built from this directory only.

Private learning state belongs in `.local-learning/`. It is ignored by Git and must never be committed or published.
