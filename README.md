# AI Foundation Handbook | AI 基础模型手册

An open, bilingual handbook on how large language models work, from attention and Transformer blocks to training, evaluation, and agent systems. The Chinese and English editions share a nine-chapter structure. Each chapter includes explanations, key distinctions, practice questions, and reference answers.

一份中英双语的基础模型学习手册。从 Attention、Transformer Block 出发，逐步理解生成、训练、评估和 Agent 系统。两种语言均按九章组织，每章包含讲解、关键边界、理解题与参考答案。
